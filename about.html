A secure, local-network shift management platform for transitional housing facilities.

About

ShiftPoint is a real-time digital shift logging system designed to replace paper-based shift records in transitional housing and residential care facilities. It runs entirely on your local network — no cloud, no subscription, no data leaving the building.

Built to handle the realities of 24/7 staffing: multiple monitors per shift, mobile wellness checks, urinalysis tracking with photo documentation, resident roster management, and archivable shift reports for compliance and supervisory review.

Technology

Built with
Node.js Express SQLite (sql.js) WebSocket PBKDF2-SHA512 Vanilla JS HTML / CSS
Runs on Windows 10/11. No cloud dependencies. All data stored locally in data\shift.db
Security
Password Hashing
PBKDF2-SHA512 — 600k iterations
Session
HttpOnly, SameSite=Lax, 12hr expiry
Auth
Role-based: Monitor / Supervisor / Admin
Transport
LAN only — optional HTTPS/TLS
CORS
Dynamic allowlist — localhost + LAN IP
Rate Limiting
Login: 10/15min • API: 300/min (persisted)
